Thinking Machines Lab の Inkling-2-Mini、量子化で Mac 向け5.4GBに

Thinking Machines Lab が Apache 2.0 で公開したマルチモーダルのオープンウェイトモデル Inkling-2-Mini（総パラメータ26.4B、1トークンあたりの稼働は3.4B、中間層をループで繰り返し使う MoE）。開発者 ShinMegamiBoson の量子化ツール lookatmyquant は、部品ごとに圧縮への弱さを測って圧縮のかけ方を変え、Apple Silicon（MLX）向けに最小5.38GBのビルドを作った。一番大きいビルドは、作者のテストで元モデルと同じ成績だったという。

何が変わるか：データを社外に出さずに使えるAIの選択肢が、手元の PC まで広がった。ただし圧縮済みモデルのライセンスは repo に書かれておらず、業務に使う前に確認が要る。

出典：Inkling-2-Mini in 5.4 GB Memory

LLMが hex ダンプから機械語を読み書き、DeepSeek V4.1 Flash も健闘

George Xenos と Sotiris Giannopoulos は、GPT-6.1 Sol（Codex CLI 経由）に hex ダンプだけを渡す実験をした。プログラムの正体の特定、バグの発見、バイトを直接書き換えての機能追加、仕様書からの ELF 作成、マルウェア解析ができた。オープンウェイトの DeepSeek V4.1 Flash もマルウェアについて同じ結論に届き、API 名は13個中9個を当てたが、推論トークンは約17倍かかった。

何が変わるか：ソースが失われた古いソフトの調査や、怪しいファイルの最初の見立てに使える可能性がある。ただし試したのは小さなプログラムだけで、マルウェアの比較も1サンプルだけ。

出典：LLMs can read and write executables byte by byte from a hex dump

GnuPG の部品 GPGME に致命的なダブルフリー、2.3.1で修正

GnuPG プロジェクトは、GPGME の status 行を読む処理にダブルフリーのバグ（CVE-2026-129975）があると発表した。とても長いユーザーIDを持つ細工された鍵で起き、データ漏えいのおそれがあり、RCE も否定できないという。2.3.1 より前のすべてのバージョンが対象で、修正済みの 2.3.1 と、古いバージョン向けのパッチが出ている。

何が変わるか：暗号と署名の土台になる部品の穴は、それを組み込んだアプリすべてに響くソフトウェアサプライチェーンの問題。社内で使っているかの確認と、更新が必要。

出典：RCE in Gnupg

偶然の出会い

GEOHunter：AIの答えに入り込む有料宣伝ネットワークを実測

研究チームは、中国の大手投稿サイト3つで生成エンジン最適化（GEO）業者を追跡し、関係するアカウント1,985件と、推定46万件超の宣伝投稿を見つけた。米中9つの生成エンジンでは、引用されたページの4.5〜20%がこのネットワーク由来だった。

何が変わるか：AIに直接命令しなくても、AIが読む材料を汚せば答えを動かせる。おすすめや比較をAIに頼るときは、引用元を確かめる必要がある。

出典：GEOHunter: Mapping a Generative Engine Optimization Network in the Wild
