主要ニュース

OpenAIのGPT-6、汎用AIが「たんぱく質」を設計し実験でも一部が結合

OpenAIは11月24日、最新世代のGPT-6が専用の生物AIに頼らず、言葉とコードによる推論だけでたんぱく質の構造と配列を設計できると発表した。パートナーのOnavaとの実験では、5つの標的に対して322個の小型たんぱく質を試し、約1割が結合。既知構造への再設計では88個中75個が結合した例もあった。

何が変わるか：文章生成の汎用AIが、これまで専用モデルの独壇場だった科学的分子設計に踏み込んだ象徴的な一歩。ただし絞り込みには専用AIがなお必要で、全体構造予測は専用モデルに劣るなど「でこぼこした実力」も残る。

出典：GPT-6 models demonstrate intrinsic protein-design capabilities

Ternary Bonsai 2.5 27B公開 — 重みを3値に、約6ギガで動くオープンウェイト

PrismMLが11月24日、ターナリー（3値）量子化のオープンウェイトモデルTernary Bonsai 2.5 27Bを公開した。アリババ系Qwen3.8 27Bを土台に、重みをマイナス1・ゼロ・プラス1の3値へ圧縮し、置き場所を約5.9ギガに抑える。SWE-benchでは元モデルの80点台に対し75点台とコーディング力を保つ。ライセンスはApache 2.0で、Hugging FaceにGGUF形式の重みが実在する。

何が変わるか：機密データを外に出さず、安価な一台のパソコンでも実用的に動く軽量な高性能モデルの好例。中国発モデルを土台に、大きさと賢さの妥協点を探るオープンウェイトの進み方を示す。

出典：Ternary Bonsai 2.5 27B

Claude Code v2.1.332 — MCPサーバーからスキルを配布、危険な命令を止める新フックも

Anthropicの開発ツールClaude Codeがv2.1.332を公開。MCPサーバー経由で「スキル」（作業手順のまとまり)を配れるようになり、メニューに『サーバー名:スキル名』の形で並ぶ。あわせてPreSkillShellCommandフックが追加され、スキルが読み込み時に裏で実行しようとする命令を事前に拒否できる。ほか多数の固まる不具合や認証まわりの修正を含む。

何が変わるか：AIに自社の手順を覚えさせ、チームで配る土台が整いつつある一方、便利さには『勝手に動かさせない』歯止めが同時に必要だと示す更新。

出典：Claude Code v2.1.332

偶然の出会い

小型ロボットMicroduck、仮想訓練だけで障害物を自力回避

Hugging Faceに11月24日掲載。Pollen Roboticsの小型歩行ロボットMicroduckが、頭部の8×8距離センサーを使い、人のコントローラー指示を自動で手直しして障害物を回避する。NVIDIAが関わるIsaac LabとNewtonを使い、仮想空間で何万もの場面を練習させる『シムtoリアル』で学習。小規模な訓練は約6時間で完了し、実機でコーンを回避できた。コードや資産は公開されている。

何が変わるか：現実で失敗を繰り返すより速く安くロボットを賢くできる仮想訓練の実例。ヒューマノイド・ロボティクスの下地となる手法を具体的に見せる。

出典：Microduck Obstacle Avoidance: A Sim2Real Workflow with Isaac Lab and Newton
