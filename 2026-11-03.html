AIに任せる作業の「確認」と「止める」、そして数字の読み方

主要ニュース

Claude Code更新、AIに任せる作業へ確認・停止・通知の仕組みを追加

Claude Code v2.1.317では、クラウドの定期タスクに頼んでいないコネクタが付いたときの警告、ウェブやシェルのツールがアカウントのメールアドレスを外部に送る前の確認、Agent SDKのフックが失敗したら操作を止めるonFailure: "block"が加わった。組織の管理設定が読み込まれていないときのデスクトップでの通知や、開発者別・日別・IdPグループ別に過去の利用額を読める費用レポートAPIも追加された。

何が変わるか：AIエージェントに任せる範囲が広がる中、人への確認、止める、知らせるという仕組みが増えた。導入する組織にとっては、運用で確かめられる点が増える。

出典：Claude Code v2.1.317

「大企業のAI導入が鈍化」は質問文の変更が原因だった、次は「スーパーインテリジェンス」へ改名

Simon Willisonが米国勢調査局のBTOS調査を見直したところ、2025年11月に質問が「商品・サービスの生産での利用」から「あらゆる業務での利用」に広がっており、新旧の数字は比べられないと分かった。従業員250人以上の企業は旧質問で約12%、新質問では2026年10月に約40%。2026年10月の調査からは、大統領令を理由に「AI」が「Super Intelligence（SI）」と呼び替えられた。

何が変わるか：外部の調査グラフをAI導入の判断材料に使うときは、質問文がいつ変わったかを確かめないと読み違える。

出典：The U.S. Census Bureau and “Super Intelligence”

Trail of Bits、Codexで古い安定版Linuxへのセキュリティ修正のバックポートを数日から数時間に

Trail of BitsはCodexを使い、足りない修正を探す、パッチを古い版に合わせる、検証材料を集める、テストする、提出資料を作るまでをエージェントに任せ、人のエンジニアがレビューして提出している。2026年10月29日までに149件のCVE修正を安定版Linuxカーネルに届け、FedoraやUbuntuのパッケージにも修正を送った。

何が変わるか：安定性と安全性のどちらかを選ばされる状況を変える試みで、手間がかかり評価されにくい作業をAIの下準備で片付ける例にもなる。

出典：Backporting security fixes at scale with Codex

偶然の出会い

AIが別のモデルの重みを直接読み書きする「Weight-Space Programming」の初期実験

MIT CSAILの研究者がブログで、LLMにネットワークの重みを読ませて性質を当てさせたり、重みを書き換えさせたりする実験を報告した。Qwen3.5-0.8Bの推論ループの原因を特定の方向に突き止め、重みの約0.016%を勾配学習なしで書き換えて、数学や指示追従のスコアを上げた。編集済みモデルはHugging Faceで公開されているが、ライセンスはページに書かれていない。

何が変わるか：自社で動かす公開モデルの弱点を、学習し直さずに直せる可能性を示している。ただし査読前の初期結果で、Gemmaでは改善しなかった。

出典：Astra can read and write weights to improve Qwen
