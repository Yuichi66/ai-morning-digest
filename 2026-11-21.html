Claude Code v2.1.330：企業の管理画面と連動、グラフ機能easelも追加

AnthropicのコーディングエージェントClaude Codeがv2.1.330を公開。Enterprise Admin Consoleで管理される組織へのサインインに対応し、ログイン後に組織の設定やクラウド、ゲートウェイが自動で適用されるようになった。グラフを描く組み込み機能easelの追加、定期タスクと/loopの実行期限の7日から30日への延長、多数の不具合修正も含む。同時期にAnthropicは新規株式公開（Nasdaq、ティッカーANT）の完了を発表し、自社の手取りは約916億ドル。

何が変わるか：AIコーディングツールが個人利用から全社展開へ移るなか、設定を一括で配れる管理機能は導入判断の重要な基準になる。

出典：Claude Code v2.1.330

Thinking Machines Lab、ノートPCで動くオープンウェイト「Inkling 2 Mini」を公開

Thinking Machines Labが、総パラメータ264億・アクティブ34億のMoEモデルInkling 2 MiniをApache 2.0で公開した。中間層を繰り返すループ構造と、最初から4bit（NVFP4）での学習が特徴で、1Mトークンのコンテキストに対応する。長い手順のエージェント作業やコーディングに強く、32GB以上のMacやDGX Sparkで動き、GGUFやMLXのバージョンも用意されている。

何が変わるか：データを外に出さずに手元でエージェント作業を任せられるオープンウェイトの選択肢が、実用的な水準に近づいた。

出典：Inkling 2 Mini

OpenAI、モデルの能力を無断で写す「敵対的蒸留」への多層防御を公開

OpenAIは、他社モデルの出力を無断で集めて安全装置のないコピーを作る敵対的蒸留への対策をまとめた。推論過程を漏らさない訓練や分類器、APIでの保護により、過去の推論を引き出す攻撃の成功率はGPT-6 Astraの54.0%からGPT-6.2 Astraでは0.2%に下がったとする。複数アカウントによる組織的な抽出も調査しており、週に数千〜数万のアカウントを処分。抽出活動の一部をMoonshot AIの関係者によるものとした。

何が変わるか：AIの能力そのものが守るべき資産となり、モデルの出どころと安全装置の有無がAI選びの論点になりつつある。

出典：Combatting adversarial distillation

偶然の出会い

PGX：人型ロボットの長い作業は、段取りを古典的な仕組みに任せる

PGXは、長い手順の移動と操作を伴う作業を、物理的な条件で段階を切り替える状態機械、手作業の場面だけを担うVLA、世界座標での位置固定の3層に分ける枠組み。状態機械と位置固定は追加学習が不要で、Unitree G1の実機とシミュレーションで、比較手法より作業の達成率が上がったと報告している。

何が変わるか：AIに丸投げせず、手順は決まった仕組みに、細かい作業はAIに任せる分け方は、業務の自動化にもそのまま応用できる。

出典：PGX: Physically Grounded Execution for Long-Horizon Humanoid Loco-Manipulation
